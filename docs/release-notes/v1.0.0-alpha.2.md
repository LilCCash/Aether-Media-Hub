## Aether Alpha 2 — IPA **non firmato** (pre-release)

iOS **non installa questo file così com'è**: va firmato di nuovo con il tuo Apple ID (AltStore, Sideloadly) o con un tuo certificato. Nel repository non ci sono credenziali di firma e l'IPA **non è stato provato su un iPhone**.
Build di GitHub Actions dal commit indicato qui sotto; la release `v1.0.0-alpha.1` non è toccata.

### Novità (solo cose presenti nel codice; stato di verifica nelle note complete)
- **Grafica:** corretta la causa dei lati tagliati nella scheda dettaglio e nel carosello Home (immagini che allargavano il layout). Verificato in CI con test di geometria.
- **Riproduzione:** secondo motore **MPV (MPVKit, LGPL)** accanto ad AVPlayer, scelto da fatti letti dal file (non dai nomi); MKV riprodotto nel simulatore in CI. Badge HDR / Dolby Vision dal file; **vero Dolby Vision solo con AVPlayer**, con MPV è mappato su HDR10/SDR. Impostazioni del player (motore, HDR, tone mapping, decodifica, deband, immagine, buffer, lingue).
- **Sottotitoli da addon** (OpenSubtitles v3 consigliato in Addon, mai installato da solo), classificati e raggruppati per lingua, con hash calcolato sul dispositivo.
- **TorBox** con la tua chiave (*Impostazioni ▸ Servizi*): «In cache» / «Non in cache», riproduzione dei torrent in cache, download su conferma. Non cancella nulla nel tuo account.
- **TMDB e TheTVDB** con la tua chiave: completano solo i dati mancanti dell'addon, mai sovrascritti.
- **Cerca / Scopri:** filtri Tipo, Genere, Anno dinamici dagli addon installati; categorie di Scopri configurabili.

### Cosa NON è verificato
- Niente è stato provato su un iPhone: aspetto reale di HDR/Dolby Vision, PiP, AirPlay, Google Cast, DLNA, VoiceOver.
- **TorBox, TMDB e TheTVDB non sono mai stati contattati con un account reale** (stub e server di prova).
- Alcuni test UI **non passano** (sottotitoli, filtri di Cerca/Scopri, rilevamento HDR nel foglio informazioni): elenco in `docs/04-TESTING.md`.
- **Problema noto di sicurezza:** MPV non verifica i certificati TLS dei flussi che riproduce. Altri problemi noti dall'audit in `docs/08-ALPHA-2-NOTE.md`.
