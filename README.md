# Aether Media Hub — Android TV

App Android TV nativa di Aether Media Hub, sorella dell'app iOS (`aether-swift-features`).
Branch isolato: nessun file dell'app iOS. Documentazione in `docs/android-tv/`.

## Novità della versione 3

- Scheda titolo ricca: cast e troupe con foto, saga, voti, dettagli, sezioni da ordinare o nascondere; pagina di ogni persona con
  biografia, filmografia filtrabile e premi (Wikidata); ricerca di persone e ricerca in linguaggio naturale («thriller coreani anni 2000»).
- Player ridisegnato: schermata iniziale con «Guarda», schermata di pausa, titoli di coda, pannello in vetro con orario di fine.
- Sottotitoli: quelli della sorgente, degli addon e dell'intero catalogo OpenSubtitles.org; file SRT, VTT, ASS, MicroDVD, gzip e ZIP.
- Universi, diario e statistiche, profilo con avatar e generi, gioco dei gusti, collezioni, titoli abbandonati.
- Download di stagioni intere con i sottotitoli salvati; video dentro ZIP/RAR su TorBox; Cloud di TorBox e Real-Debrid.
- Registro diagnostico locale (Impostazioni ▸ Informazioni), senza chiavi né indirizzi completi.
